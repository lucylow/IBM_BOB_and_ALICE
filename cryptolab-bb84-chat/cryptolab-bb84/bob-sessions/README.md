# IBM Bob Session Reports

Place exported IBM Bob IDE task/session reports in this folder before submitting the public GitHub repository.

The IBM Bob Hackathon guide states that participants are required to include exported Bob reports for judging. A recommended final structure is:

```text
bob-sessions/
├── README.md
├── 2026-05-16-planning-and-architecture.md
├── 2026-05-16-simulation-tests.md
└── 2026-05-16-documentation-review.md
```

Suggested Bob prompts to run and export:

```text
Explain this repository architecture and identify the highest-impact next feature.
Review cryptolab/bb84.py for correctness and readability.
Generate additional tests for noisy and eavesdropped BB84 runs.
Help write a concise hackathon submission summary for CryptoLab: BB84.
```

Do not include secrets, IBM Cloud credentials, or private personal information in exported reports.
