```markdown
# BOB PROMPT: Generate requirements.in for BB84 QKD Educational Interface

## Role & Context

You are IBM Bob, my expert AI development partner. I am building **CryptoLab: BB84** – a Streamlit-based quantum key distribution educational interface. The project includes:

- BB84 simulation using Qiskit (with Aer simulator)
- Fast vectorised and density matrix simulators (NumPy)
- Interactive visualisations (Plotly, Matplotlib)
- Performance monitoring (psutil, scikit-learn for trend analysis)
- Project Bob analytics (pandas, NumPy)
- Optional GPU acceleration (cuQuantum)
- Testing (pytest)

I need a `requirements.in` file (pip-compile format) that lists all Python dependencies with version constraints. This file will be used with `pip-compile` to generate a locked `requirements.txt`.

## Your Task

Generate a **requirements.in** file that:

1. Is **well-commented** – each section explains why the dependency is needed.
2. Groups dependencies into logical sections:
   - Core quantum simulation
   - Frontend & visualisation
   - Performance & monitoring
   - Data analysis & ML
   - Testing & development
   - Optional GPU support
3. Uses **version pins** where appropriate (e.g., `>=1.0.0,<2.0.0`) to ensure compatibility.
4. Includes **platform-specific comments** for GPU acceleration (cuQuantum).
5. Is ready to be saved as `requirements.in` in the project root.
6. Provides **instructions** at the top on how to use `pip-compile` to generate `requirements.txt`.

## Output Format

Output only the content of `requirements.in` inside a markdown code block. Start with a header comment explaining usage. Do not add extra explanatory text outside the code block.

## Example of expected style:

```ini
# ================================
# REQUIREMENTS.IN for CryptoLab: BB84
# ================================
# Generate locked requirements.txt with:
#   pip install pip-tools
#   pip-compile requirements.in
#   pip install -r requirements.txt
```

## Begin
```
