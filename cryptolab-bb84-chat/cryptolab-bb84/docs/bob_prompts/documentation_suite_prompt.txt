## docs/installation.md

# Installation Guide

This guide covers local, Docker, and cloud VM installation for CryptoLab: BB84.

## Prerequisites

- Python 3.10 or higher
- pip and virtualenv (recommended)
- 4 GB RAM (8 GB recommended for 500+ qubits)
- Optional: NVIDIA GPU with CUDA 11+ for cuQuantum acceleration

## Local Installation (pip)

### Step 1: Clone the repository

```bash
git clone https://github.com/yourusername/cryptolab-bb84.git
cd cryptolab-bb84
```

### Step 2: Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows
```

### Step 3: Install dependencies

We use `pip-tools` for reproducible builds.

```bash
pip install pip-tools
pip-compile requirements.in
pip install -r requirements.txt
```

> [!NOTE]
> If you have an NVIDIA GPU, uncomment the `cuquantum` lines in `requirements.in` before running `pip-compile`.

### Step 4: Run the application

```bash
streamlit run app.py
```

Open http://localhost:8501.

## Docker Installation

### Build the image

```bash
docker build -t cryptolab-bb84 .
```

### Run the container

```bash
docker run -p 8501:8501 cryptolab-bb84
```

### Example Dockerfile (save as `Dockerfile`)

```dockerfile
FROM python:3.10-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8501
CMD ["streamlit", "run", "app.py", "--server.port=8501", "--server.address=0.0.0.0"]
```

## Cloud VM (AWS EC2 / GCP Compute Engine)

1. Launch an Ubuntu 22.04 instance (t3.medium or larger).
2. Install Python 3.10 and git.
3. Follow the local installation steps.
4. Open port 8501 in the security group.
5. Run `streamlit run app.py --server.port=8501 --server.address=0.0.0.0`.

> [!WARNING]
> For production, use a reverse proxy (nginx) and enable HTTPS.

## Verification

After installation, run the test suite:

```bash
pytest tests/
```

All tests should pass.
